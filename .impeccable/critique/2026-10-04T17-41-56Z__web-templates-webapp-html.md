### Priority Issues (P1–P3)

#### 1. [P1] Регрессия размеров кнопок в CSS Media Queries на компактных экранах
- **Что:** В `webapp.css` по умолчанию кнопки сбалансированы: Dislike 56px, Like 56px, Superlike 44px, Rewind 44px. Однако в медиа-запросах (`@media (max-height: 700px)` и `@media (max-height: 620px)`) остались старые правила: Superlike задан как 58px / 52px, а Dislike/Like уменьшаются до 48px / 44px, кнопка отката отсутствует.
- **Почему это важно:** На компактных смартфонах (iPhone SE, малый экран в Telegram) возвращается ловушка для большого пальца.
- **Решение:** Пропорционально масштабировать все 4 кнопки в медиа-запросах (Dislike/Like 48px/42px, Superlike и Rewind 38px/34px).
- **Команда:** `$impeccable polish web/static/webapp/webapp.css`

#### 2. [P2] Перегрузка первого экрана в режиме романтических знакомств
- **Что:** На экране `screen-explore` в режиме «Знакомства» вертикальный стек (шапка + истории + карточка с тегами + ряд кнопок + док) сжимает фотографию на экранах высотой менее 750px.
- **Почему это важно:** Студенты оценивают анкету в первую очередь по фото и интересам; био обрезается.
- **Решение:** Сворачивать блок историй при скролле карточки или открывать истории отдельной компактной кнопкой.
- **Команда:** `$impeccable distill web/templates/webapp.html`

#### 3. [P2] Казино-стилистика Колеса Фортуны
- **Что:** Механика вращающегося колеса фортуны со спинами диссонирует с университетской концепцией студклуба и акселератора.
- **Почему это важно:** Снижает академическую солидность платформы.
- **Решение:** Переосмыслить механику как «Студенческий Грант» / «Зачётную Лотерею» с академической эстетикой билетов и зачёток.
- **Команда:** `$impeccable clarify web/templates/webapp.html`

#### 4. [P3] Типографическое выравнивание с DESIGN.md
- **Что:** Подключен `Plus Jakarta Sans`, хотя дизайн-система `DESIGN.md` регламентирует `Cabinet Grotesk` / `Satoshi` для заголовков и `JetBrains Mono` для рейтингов и баланса.
- **Почему это важно:** Нарушение заявленного дизайн-кода.
- **Решение:** Подключить `JetBrains Mono` для чипов с цифрами и `Satoshi` для дисплейных заголовков.
- **Команда:** `$impeccable typeset web/templates/webapp.html`
